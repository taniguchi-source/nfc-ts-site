FEATURE 01

クラウドで一元管理

NFCタグを回収することなく、クラウド管理画面からコンテンツをいつでも・何度でも更新できます。キャンペーン終了後もタグを無駄にせず、新しい情報に切り替えて継続利用できます。

  • ✓
    リアルタイムコンテンツ更新

    URLや動画・PDF・画像をブラウザ管理画面から即時変更。タグを回収・再配布する手間が不要です。

  • ✓
    複数タグの一括管理

    数十〜数万枚のタグをグループ化して一括更新。イベントごと・商品ラインごとの管理も簡単です。

  • ✓
    スケジュール配信

    「期間限定キャンペーン」「予約公開」などの配信スケジュールを事前に設定できます。

  • ✓
    対応コンテンツ形式

    URL・動画（YouTube/Vimeo）・PDF・画像・テキスト・SNSプロフィールなど多形式に対応。

FEATURE 02

セキュリティ・真贋判定

NFCタグの固有ID（UID）を活用した認証システムで、コピー品・偽造品を確実に排除します。ブランド保護と顧客の信頼確保に貢献します。

  • ✓
    NFCタグ固有ID認証

    各タグに割り当てられた固有UID（変更不可）をサーバー側で照合。コピーしても認証できない仕組みです。

  • ✓
    ワンタイムURL発行

    読み取るたびに異なるURLを生成するオプション。スクリーンショット共有やリンクコピーによる不正アクセスを防止します。

  • ✓
    アクセス履歴の完全記録

    いつ・どの端末から・どの場所でアクセスされたかを記録。不審なアクセスパターンを検出できます。

  • ✓
    アクセス制限・無効化

    紛失・盗難時には管理画面から即座にタグを無効化。特定期間や特定地域からのアクセスを制限する設定も可能です。

FEATURE 03

データマーケティング連携

Googleアナリティクスと連携し、顧客がNFCタグを「いつ・どこで・どの端末で」読み取ったかをリアルタイムで可視化。ノベルティの効果検証を定量的に行えます。

  • ✓
    Googleアナリティクス連携

    GA4と連携し、読み取り数・ユニークユーザー数・地域別分布・時間帯分析などを自動集計します。

  • ✓
    読み取り位置情報の取得

    GPS情報（同意取得済みユーザー）と組み合わせ、どの地域でよく読み取られているかを地図上で可視化できます。

  • ✓
    カスタムイベントトラッキング

    「動画再生」「PDF閲覧」「問い合わせクリック」などのユーザー行動を計測し、コンテンツ改善に活用できます。

  • ✓
    定期レポート出力

    月次・週次のアクセスレポートをCSV・PDF形式でダウンロード。経営報告・クライアント報告にも活用できます。

FEATURE 04

自由なデザイン・形状

NFCタグの形状・素材・デザインは完全カスタマイズ対応。既存の印刷物にNFC機能を後付けすることも可能で、ブランドの世界観を損なわずに導入できます。

  • ✓
    多様な形状・素材に対応

    カード型（名刺サイズ〜A4）・シール型（各種サイズ）・タグ型・キーホルダー型など。PET・紙・PVC・金属など素材も選択可能。

  • ✓
    既存印刷物への後付け対応

    既にある招待状・パッケージ・名刺などにNFCシールを貼り付けるだけでNFC機能を追加できます。デザイン変更不要。

  • ✓
    高品質印刷との両立

    オフセット印刷・UV印刷・箔押し・エンボス加工などの高品質印刷とNFC機能を同時に実現できます。

  • ✓
    谷口松雄堂のデザイン力

    70年以上の印刷・紙製品製造の実績を持つ谷口松雄堂が、デザインから製造まで一貫してサポートします。

FEATURE 05

B2B一括管理とB2C専用スタジオ

企業による一括管理（B2B）から、エンドユーザー自身がコンテンツを作る（B2C）まで、1つのシステムで柔軟に切り替え可能。配布して終わりではなく、受け取った人が「自分のもの」として使い続けられる仕組みです。

  • ✓
    B2B：数千枚を一括管理

    何千枚というNFCタグでも、管理画面からチェックボックスで選択して一括で遷移先（URL・動画など）を変更。QRコードのように1枚ずつ作り直す必要はありません。

  • ✓
    B2Cへのワンタッチ切替

    企業側の割り当てを解除するだけで、エンドユーザー向けのタグとして販売・譲渡が可能に。1つのタグを用途に応じて使い分けられます。

  • ✓
    専用スタジオ機能

    ユーザー自身がメールアドレスで登録し、写真アルバム・動画メッセージ・デジタル名刺（プロフィール）などを直感的に作成・公開できます。

  • ✓
    「動く色紙」のような体験を

    購入したユーザーがNFCを読み込んで画像・動画の「アルバム」を作成。手書きの色紙やギフトと一緒に、デジタルな思い出を届けられます。
