導入事例

NFC-TSをご活用いただいたお客様の事例をご紹介します。

USE CASES

活用シーン

扇子・色紙・御朱印帳・貼り箱など、谷口松雄堂が製造する和小物すべてにNFC-TSを組み込めます。

🪭

扇子・和小物

扇子や御朱印帳にNFCタグを内蔵。スマホをかざすだけで職人の制作動画・ブランドストーリー・限定コンテンツを届けます。谷口松雄堂の製品力がそのままデジタル体験に変わります。

  • 扇子へのNFC内蔵
  • 御朱印帳・和紙製品
  • 職人紹介・制作動画連携
🎁

贈答品・ギフト

色紙・貼り箱・紙袋などギフト商品にNFCタグを付加。受け取った方がタグをかざすと、贈り手のメッセージ動画や商品ストーリーが再生され、感動体験を演出します。

  • 寄せ書き色紙＋動画メッセージ
  • 貼り箱・ギフトボックス
  • 特産品・記念品パッケージ
🏢

企業ノベルティ・OEM

展示会ノベルティ・記念品・名刺にNFCを搭載したOEM製造が可能。年間1,868件の実績を持つ谷口松雄堂が、企画から製造・クラウド設定まで一貫対応します。

  • 展示会・イベントノベルティ
  • 周年記念品・贈答品
  • NFCデジタル名刺
和小物
📖

御朱印帳へのNFC搭載

京都府 / 神社・仏閣様

谷口松雄堂製の御朱印帳にNFCタグを内蔵。スマートフォンをかざすだけで、境内の由緒・ご神体の解説動画・限定デジタル御朱印コレクションにアクセスできる体験を提供。授与所での販売単価も向上。

  • 授与所での御朱印帳の販売数が1.8倍に増加
  • デジタルコンテンツの季節ごと更新で参拝リピーターが増加
  • 観光客の滞在時間・SNS投稿数が増加
ギフト・贈答
🖌️

NFC色紙で動画メッセージを届ける

関西圏 / 企業・団体様

退職・卒業・受賞などの節目に贈る色紙にNFCタグを搭載。紙面のメッセージに加え、スマートフォンをかざすと同僚・仲間からの動画メッセージ集が再生される「動く色紙」を実現。

  • 受け取った方から「一生の宝物」と大好評
  • 動画メッセージを後から追加できる機能が喜ばれる
  • 社内の他部署・他拠点でも口コミで採用が拡大
カード・名刺

プラスチックカードへのNFC内蔵

大阪府 / 小売・サービス業様

会員証・ポイントカードにNFCタグを内蔵。カードをかざすだけでポイント確認・クーポン取得・限定コンテンツへのアクセスが可能に。カード表面のデザインは変えずにデジタル機能を追加。

  • カードのタップ利用率 67%（3ヶ月後）
  • クーポン利用率が紙クーポン比 2.4倍 に向上
  • 来店頻度・客単価ともに改善

NFC内蔵デジタル名刺の導入

京都府・大阪府 / IT・コンサル企業様

従来の名刺にNFCタグを搭載し、タップするだけで会社HP・実績ポートフォリオ・SNSプロフィールへ誘導。異動・担当変更時もクラウドから即時更新でき、名刺を刷り直す必要がなくなった。

  • 商談後のWeb訪問率が3.1倍に増加
  • 名刺の印刷・管理コストを年間35%削減
  • 「記憶に残る名刺」として商談先での話題に
